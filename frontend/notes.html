🤖 Manual de Prompts — Segundo Cerebro
Copia y pega estos prompts en Claude Code para activar cada protocolo. Inicia sesión en las plataformas antes de ejecutar los escaneos.
· 🚀 inicio de sesión ·
P0 — Protocolo Cerebro (Inicio de Sesión)
Inicia el protocolo Cerebro. Lee el CLAUDE.md, revisa el CEREBRO_STATE.md y muéstrame el menú principal de módulos. Antes de preguntar, ejecuta automáticamente: (1) Actualiza data/deals.json con las mejores ofertas GRATIS del momento buscando en Cajita Tech, Epic Games Store, Udemy cupones gratis, Amazon Luna, GOG giveaways, Steam free-to-play, y tiendas Colombia (MercadoLibre, Éxito). (2) Actualiza las búsquedas de empleo: busca vacantes nuevas para AP/AR Specialist, Data Analyst, Finance remoto LATAM y agrega las mejores al VacancyDB. (3) Muéstrame el menú de módulos.
📋 Al inicio de cada sesión: auto-actualiza ofertas gratis (deals.json) + vacantes nuevas (VacancyDB) + carga contexto.
· 🔄 10-SYS — escaneos CUN ·
P1 — Escaneo Completo CUN (4 plataformas)
CEREBRO: SCAN CUN — Escanea las 4 plataformas CUN abiertas en Chrome: (1) CUN Digital → Mis cursos → entrar a cada curso, extraer actividades y % completado. (2) SGA Campus → notr29 → notas por materia del 26V02. (3) CUN 360 → Dashboard (deuda, docs) + clic "Consultar Materias Virtuales" (docentes) + Historial. (4) Gmail CUN → inbox alertas. Actualiza academic-8vo.json, systems_logic.js (SUBJECTS con docentes) y CEREBRO_STATE.md. Además: actualiza data/deals.json con ofertas GRATIS frescas y actualiza el VacancyDB con vacantes nuevas. Actualiza prompts si hay cambios.
🔑 Requisito: Abrir portales CUN desde 10-SYS → CUN Hub → "Abrir Todos" e iniciar sesión en las 4 plataformas.
P2 — Solo Notas Actuales (SGA)
CEREBRO: SCAN NOTAS — Lee la tab del SGA Campus (notr29) y extrae las notas actuales del período 26V02. Actualiza academic-8vo.json con las calificaciones, promedios y risk_level por materia. Si hay notas nuevas, actualiza el CEREBRO_STATE.md.
📊 Para actualizar calificaciones. Haz doble clic en el período 26V02 para ver sub-notas.
P3 — Historial + Docentes (CUN 360)
CEREBRO: SCAN HISTORIAL — Lee CUN 360: (1) Académico → Historial de notas (52+ materias, paginar con Angular paginator). (2) Dashboard → clic "Consultar Materias Virtuales" → extraer docentes asignados. (3) Financiero → verificar deuda. Actualiza academic-history.json y academic-8vo.json (professors). Actualiza CEREBRO_STATE.md.
📊 CUN 360 es Angular SPA. Usar read_page + computer (clicks) para navegar modales y paginación.
P4 — Tareas de CUN Digital (Moodle)
CEREBRO: SCAN TAREAS — Lee CUN Digital → "Mis cursos" → entrar a CADA curso activo → extraer actividades pendientes (tareas, foros, quizzes) con fechas de entrega y estado. Agrégalas al task manager del módulo 10-SYS vía bulkImport o addTask. Actualiza CEREBRO_STATE.md con las tareas encontradas.
📚 Navega cada sección del Moodle. Las tareas se importan al semáforo con materia + fecha límite.
P4b — Actualizar Docentes (CUN 360)
CEREBRO: SCAN DOCENTES — Abre CUN 360 Dashboard → scroll hasta "Consultar Materias Virtuales" → clic → extraer nombres de docentes asignados a cada materia. Actualiza SUBJECTS[] en systems_logic.js (campo professor) y academic-8vo.json. Actualiza CEREBRO_STATE.md.
👨‍🏫 Los docentes aparecen en el modal "Horario - Modalidad Virtual" de CUN 360.
· 💼 2-APP — job hunting ·
P5 — Analizar Vacante
CEREBRO: ANALIZAR VACANTE — Abre el módulo 2-APP (apply.html). Pega el job description en el Analizador tab → runAnalysis(). Genera automáticamente en los 5 tabs: (1) Análisis ATS con score por sinónimos, (2) CV Perfilado con keywords tejidas y 3 perfiles, (3) Cover Letter con 2 templates (formal/startup) + app msg + LinkedIn msg, (4) Interview Prep con 13 Q&A STAR rankeadas por JD + TTS, (5) Prompt Lab con 3 prompts IA (Mock Interviewer, Tech Assessment, Salary Negotiator).
🎯 Motor ATS v2 cruza JD contra my-skills.json con sinónimos. Export PDF disponible en CV Weaver.
P6 — Buscar Vacantes
CEREBRO: BUSCAR TRABAJO — Abre el módulo Job Tracker (jobs.html). Usa las 12 Quick Searches optimizadas para LinkedIn, Indeed y Google Jobs. Guarda vacantes interesantes en el Kanban.
🔍 12 búsquedas preconfiguradas para AP/AR Specialist, Data Entry, Finance roles LATAM remoto.
· 🇺🇸 3-ENG — english practice ·
P7 — Practicar Entrevista en Inglés
CEREBRO: ENGLISH DOJO — Abre el módulo 3-ENG (english.html). Usa el TTS para escuchar preguntas del recruiter y el STT (micrófono) para grabar tus respuestas en inglés. Compara con la respuesta ideal STAR.
🎙️ Usa Web Speech API: TTS (voz US English) + STT (webkitSpeechRecognition para transcribir).
· 📊 4-RUT — excel practice ·
P8 — Practicar Excel Técnico
CEREBRO: EXCEL DOJO — Abre el módulo 4-RUT (ruta.html). Practica los 15 escenarios de AP/Finance: XLOOKUP, INDEX/MATCH, SUMIFS, aging buckets. Las celdas se animan al resolver correctamente.
📝 15 escenarios realistas con validación de fórmulas y explicaciones paso a paso en español.
· 🛠️ mantenimiento ·
P9 — Auditar Todos los Módulos
CEREBRO: AUDITAR — Lee el CEREBRO_STATE.md y audita el estado de todos los módulos del sistema. Identifica módulos pendientes, bugs conocidos y próximas mejoras. Verifica que los prompts en CLAUDE.md y notes.html reflejen las capacidades actuales. Muestra un reporte completo.
🔧 Para verificar integridad del sistema, prompts actualizados, y planificar sprints de mejora.
P10 — Commit y Push
CEREBRO: DEPLOY — Haz git add, commit con mensaje descriptivo y push al repositorio. Antes de hacer push: actualiza CEREBRO_STATE.md con los cambios, y verifica que los prompts (CLAUDE.md + notes.html) estén al día con las funcionalidades implementadas.
🚀 Siempre hacer al final de cada sesión. Incluye verificación de prompts actualizados.
P11 — Guía de Materia (Task Guide)
CEREBRO: GUÍA [materia] — Abre el módulo 10-SYS y muestra la guía paso a paso de la materia indicada. El Task Guide Modal muestra: docente asignado, dónde está el aula virtual, tipo de evidencia, cómo entregar, 5 pasos semanales y tips importantes. Materias disponibles: mat_especiales, calidad_sw, admin_bd, ing_web, redes, inv_ciencia, english_beginner, placement_test.
📖 También puedes tocar cualquier materia en el Subject Health Grid del Dashboard para ver la guía.
P12 — Analizar Clase Perdida (Video)
CEREBRO: ANALIZA CLASE URL: [pegar link del video aquí] Materia: [nombre de la materia] Protocolo: 1. Abre la URL en Chrome MCP o extrae su contenido (título, descripción, transcript/captions). 2. Busca en web los temas típicos de esa materia en la CUN (Ingeniería de Sistemas Virtual). 3. Genera informe estructurado: - Resumen ejecutivo (qué se vio en la clase) - Temas principales (lista de conceptos) - Qué debo hacer (actividades/tareas detectadas o inferidas) - Cómo y dónde entregar (evidencia, plataforma Moodle, método) - Cuándo entregar (deadline si se menciona, sino indicar "consultar aula") - Recursos recomendados para estudiar el tema 4. Navega a http://localhost:3456/systems.html tab "Clases Perdidas" e inyecta con: SYS.injectClassSession({ url, subject_id, subject_name, date, title, summary, topics:[], assignments:[{title,desc,due_date,submit_where,submit_how,evidence_type,moodle_url}], resources:[] }) 5. Confirma guardado y muestra el informe completo.
📹 10-SYS → Tab "Clases Perdidas" → genera el prompt automáticamente al pegar la URL. O usa este prompt copiando y editando el link.
📖 Flujo de trabajo recomendado:
1. Abrir Claude Code → Pegar P0 (Protocolo Cerebro)
2. Claude carga el contexto y muestra el menú de módulos
3. Elegir módulo → Si es 10-SYS: abrir portales CUN, iniciar sesión, pegar P1-P4b
4. Trabajar en el módulo seleccionado
5. Para ver guía de materia → Pegar P11 o tocar materia en Dashboard
6. Para analizar clase perdida → 10-SYS → "📹 Clases Perdidas" → pegar URL → copiar prompt → pegar en Claude (P12)
7. Al terminar → Pegar P10 (Deploy) — actualiza código, CEREBRO_STATE y prompts
